# Wedding photographs

Add your JPG, JPEG, PNG, WebP or AVIF photos here. When you commit them to the `main` branch of GitHub, the **Publish wedding memory page** workflow automatically finds and adds them to the slideshow. You never have to change HTML or edit a file list. (The photo folder is scanned at deployment.)

Photos with identical file contents are included only once. Distinct colour and black-and-white versions count as different photographs by design.

**Important:** The starting portrait is `cover.jpg`. You can replace that file if you'd like a different resting portrait.

**Important:** The linked group sequence must keep these exact names:

1. `FB_IMG_1792178908223.jpg` — normal group photograph
2. `FB_IMG_1792178854679.jpg` — group cheering

They are treated as a single story moment. They play consecutively (normal first, cheers second), and never appear as independent random images. If either one is missing, both will be excluded from the slideshow to preserve the pair.

Keep the `photos` folder reasonably small to make mobile loading quick. Images are displayed faithfully without altering faces or people.
